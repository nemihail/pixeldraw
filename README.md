Описание проекта

Pixeldraw - это простое графическое приложение на Python, созданное с использованием библиотеки tkinter.
Программа позволяет создавать пиксель-арт рисунки в сетке 10×10, кликая по клеткам.

### Основные возможности

- Сетка 10х10 для рисования
- Интерактивное изменение цвета клеток
- Простой и интуитивно понятный интерфейс
- Фиксированный размер рабочей области

### Как использовать

1. Запустите программу
2. Кликните левой кнопкой мыши по любой черной клетке
3. Клетка изменит цвет на белый
4. "Рисуйте", кликая по нужным клеткам

### Требования

- Python 3.x
- Библиотека tkinter

### Установка и запуск

1. Скопируйте код в файл pixeldraw.py
2. Запустите командой:

```bash
python pixeldraw.py
```

### Структура кода

- mainloop() - главный цикл обработки событий
- tk.Button() - создание интерактивных клеток
- bind() - привязка функции к событию клика
- grid() - размещение виджетов в сетке
